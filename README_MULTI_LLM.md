# ⚡ MOKAFAD - Solution Soumission IA

Application de pré-qualification d'appels d'offre pour entreprises électriciennes.

## 🚀 Fonctionnalités

- ✅ Inscription et authentification sécurisées
- ✅ Profil entreprise complet (logo, spécialités, projets antérieurs)
- ✅ Analyse IA d'appels d'offre avec comparaison des projets antérieurs
- ✅ Multi-LLM avec fallback automatique (Gemini, Groq, OpenAI)
- ✅ Stockage sécurisé de documents PDF
- ✅ Tableau de bord avec statistiques

## 📋 Prérequis

- Python 3.9+
- Compte Supabase
- Clé API Gemini (recommandé) ou Groq ou OpenAI
